Seraphina OS Harness

Sign in with your access token

Where is the token? On the server, run:

factory url

It prints a login link that already contains the token: open it and you are signed in. The token is also stored as server.token in ~/.config/software-factory/config.json.

Working remotely? Tunnel the port first, then open the link on this machine:

ssh -N -L 8765:127.0.0.1:8765 you@server
